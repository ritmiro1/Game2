# ПАЛИМПСЕСТ: Протокол Эха

Оригинальная соревновательная игра в жанре **тактической дуэли одновременных приказов**. Два редактора реальности спорят за три эпохи города Вэй. Каждый сыгранный приказ возвращается Эхом через два раунда — с открытой для обоих игроков целью и силой 60%.

## Что внутри

- 21 уникальный приказ и 4 редактора с разными пассивными свойствами и подписными картами.
- Три независимые эпохи, инициатива, Темп, щиты, Целостность, заряд и открытая лента будущих Эхов.
- Три уровня ботов. «Оракул» оценивает вероятностные ответы и смотрит на следующий раунд, но функция выбора вообще не принимает скрытый ход человека.
- Рейтинговая и свободная очередь, открытые и приватные комнаты по коду, Elo, топ игроков, повторная дуэль, сигналы и таймер.
- Авторитетный WebSocket-сервер: скрытые руки, проверка приказов, переподключение, защита от подмены результата клиентом.
- Анимированный интерфейс, авторские образы, процедурные звуки, академия, арсенал и сюжетная летопись.
- Локальный режим полностью работает без интернета. Рейтинг начисляется только за сетевые дуэли.

## Запуск для разработки

Требуется Node.js 22+.

```bash
npm ci
npm run dev
```

Клиент: `http://localhost:5173`. Авторитетный сервер: `http://localhost:3000`.

### Проверка и production

```bash
npm test          # движок, Эхи, боты и стресс-тест полных дуэлей
npm run build     # статический клиент в dist/
npm start         # единый HTTP + WebSocket сервер на 0.0.0.0:3000
```

Переменная `PORT` меняет порт сервера. Для отдельного клиента можно задать `VITE_SERVER_URL=wss://host/ws` при сборке. Профили и рейтинг сохраняются в `server/data/players.json`; файл атомарно перезаписывается и исключён из Git.

## Windows .exe

```bash
npm run dist:win
```

Bun компилирует нативное portable-приложение в `release/`: клиент, шрифты, изображения и боты встроены в один `.exe`. Установка не требуется; используется системный WebView2 (предустановлен в Windows 11). Локальные дуэли доступны сразу. Для сетевой игры exe использует WebSocket-сервер, указанный при сборке; собственный адрес можно передать через `PALIMPSEST_SERVER_URL` при сборке или запуске.

GitHub Actions собирает Windows x64 по тегу `v*` или вручную через **Windows portable build**.

## Правила в двух абзацах

Оба игрока одновременно выбирают по приказу из руки в пять карт. Больший Темп разрешается раньше; при равенстве помогает инициатива. Приказ тратит заряд, а затем создаёт Эхо на два раунда вперёд. Эхо разрешается до новых приказов и повторяет только числовые эффекты с силой 60%. В конце раунда оба получают +2 заряда, а временные щиты сгорают.

Сдвиг эпохи на отметку 6 фиксирует её за игроком и наносит сопернику урон. Побеждает захват двух эпох или обнуление 28 Целостности соперника. Если линия продержалась 20 раундов, Архив сравнивает эпохи, Целостность, контроль и нанесённый урон.

## Структура

- `shared/` — контент, детерминированный движок и ИИ без доступа к скрытому ходу.
- `server/` — HTTP API, WebSocket-комнаты, очередь, рейтинг и переподключение.
- `src/` — React-клиент, анимации, экраны и локальный режим.
- `desktop/` — автономная Bun + WebView2 оболочка и встроенный локальный источник ресурсов.
- `tests/` — автоматические проверки и стресс-тесты.

Сетевой транспорт не доверяет клиенту: клиент отправляет только `cardId` и `target`; урон, Эхи, рука, стоимость, победитель и Elo вычисляются на сервере.
