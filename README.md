# Ладья — шахматы и управление вкладками

Локальное расширение для Яндекс Браузера: восстановление недавно закрытых вкладок, безопасная очистка неактивных вкладок и управление звуком — плюс шахматный тренер на локальном Stockfish.

## Быстрый запуск

Открой `browser://extensions`, включи режим разработчика, выбери **«Загрузить распакованное расширение»** и укажи папку `extension/`.

Подробности, разрешения и описание режимов — в [`extension/README.md`](extension/README.md).

Stockfish, русскоязычная офлайн-озвучка eSpeak и остальные игровые ресурсы включены в расширение. Для работы не нужен аккаунт, сервер или интернет-соединение.
