# LifeOS 0.1.0 preview — фактическое состояние реализации

Дата проверки: **12 ноября 2026 года**. Это отчёт о сделанном, а не замена исходной [продуктовой спецификации](LifeOS-specification.ru.md).

**Исходное ТЗ полностью не закрыто.** Особенно важно: обычная установка LifeOS пока **не создаёт дополнительный монитор Windows**. Полноценного постоянно работающего поискового сервиса с широким охватом интернета тоже нет.

## Реализовано

| Компонент | Фактический результат |
| --- | --- |
| Windows EXE | Сборка установщика NSIS и portable-приложения; публикация GitHub prerelease; контрольные суммы SHA-256. |
| Оболочка | Рабочий стол, меню запуска, док, окна с перемещением/изменением размеров, пространства, темы, сохранение раскладки. Это приложение поверх Windows, а не новый загрузочный kernel. |
| Личные приложения | Задачи и повторы, заметки и дневник, календарь, проекты, ежедневные привычки, фокус, ручной учёт RUB, закладки и выбранные файлы. Все показатели вычисляются из настоящих записей. Стартовые задачи/заметка прямо обозначены как ознакомительные. |
| Хранение | Локальный SQLite с WAL, транзакциями и FTS5; JSON-экспорт/импорт, резервная копия перед импортом, проверка конфликтов заметок и входных данных. Полное шифрование не реализовано. |
| Браузер | Собственная оболочка браузера на Chromium/Electron WebContentsView, вкладки, изолированные cookie-профили, временные приватные сессии, загрузки. Движок Chromium не является собственной разработкой LifeOS. |
| Поиск | Свои crawler, очередь URL, SQLite-индекс, ранжирование и API. Это не Google/Bing и не поиск только по заметкам. Публикации реально загружаются по HTTP(S); пустота индекса не заменяется вымышленными результатами. |
| Дисплеи | Перечисление настоящих Windows-дисплеев и перенос окна на существующий экран; исходный Viewer для захвата выбранного неосновного дисплея. |
| Драйвер | Экспериментальная адаптация Microsoft IddSample на UMDF/IddCx: один монитор, LifeOS EDID/идентичность, отдельный software-device host. **Проверка компиляции SDK/WDK успешна; подписи, установки и аппаратного теста нет.** |

## Что действительно проверено

### Core и интерфейс

- `npm test`: **22 теста пройдены**, включая сохранение после перезапуска SQLite, конфликты, циклы зависимостей, повторы на границах месяца, атомарный импорт, некорректные поля и запрет воскрешения удалённой заметки поздним сохранением.
- Проверены обновление/удаление индексируемого документа, robots.txt, noindex, RSS/Atom/sitemap, сохранение очереди обхода между перезапусками, SSRF и отделение даты публикации от даты загрузки.
- `npm run build`: строгая TypeScript-проверка и Vite production build успешны.
- `npm run test:e2e`: задачи, завершение, автосохранение заметок, немедленное переключение заметок, безопасный Markdown, фокус в модальном окне, поисковый интерфейс, честные ограничения дисплея, меню/горячие клавиши, отсутствие необработанных ошибок и горизонтального переполнения мобильного рабочего стола.
- `npm run test:e2e:workflows`: проект и связанная задача, отметка привычки, календарное событие и настоящий ICS-файл, финансовая операция с копейками и CSV-файл, запуск/пауза/продолжение/завершение фокуса.
- `npm audit --omit=dev --audit-level=high`: на момент проверки известных уязвимостей production-зависимостей не обнаружено. Это **не** полноценный аудит безопасности.

### Windows EXE

Сборки выполняются на **Windows Server 2022 в GitHub Actions**. Это не аппаратный прогон на пользовательском Windows 11 ПК.

Пройдены запуски:

1. Electron из исходного проекта.
2. Упакованного `win-unpacked/LifeOS.exe`.
3. Настоящего `LifeOS-0.1.0-Portable-x64.exe`.
4. Установщика в тихом режиме и затем установленного `LifeOS.exe`.

Каждый запуск проверяет renderer/preload, SQLite CRUD и завершение задачи, загрузку реальной контролируемой HTTP-страницы в WebContentsView, отсутствие Node.js и привилегированного LifeOS bridge у сайта, видимость вкладок, запрет опасных URL-схем, разделение cookies, непостоянство приватных вкладок, уничтожение WebContents при закрытии и перечисление существующих дисплеев. Контролируемая HTTP-страница — тест изоляции браузера, **не доказательство покрытия интернета**.

В выпуск включён `Windows-smoke.json` с результатами трёх упакованных вариантов и версиями runtime. EXE пока **не подписаны Authenticode**.

## Реальный охват поиска и его ограничения

В ограниченной среде разработки реально проверены HTTP-загрузка и индексация GitHub release-страниц. Часть индивидуальных публикаций не индексируется из-за noindex; обход запрещённых robots.txt адресов не подменяется обходным API. NASA и Habr в этой среде недоступны из-за сетевого списка разрешённых доменов — соответствующие ошибки показываются в состоянии источников.

На обычном ПК LifeOS может обращаться к другим публичным источникам при доступном интернете и разрешающей политике сайта. Проверка всего их содержимого в этой среде **не проводилась**.

Ограничения preview:

- первоначальный набор источников мал;
- по умолчанию три URL на источник за проход, проход каждые 30 минут;
- постоянная очередь ограничена 1000 URL на источник и глубиной два перехода;
- проверка старых страниц планируется отдельно; метаданные публикации не выдумываются;
- локальный индекс обновляется, только пока работает приложение;
- отдельный `SearchServer.zip` содержит исходники backend, **не** автоматически развёрнутый публичный сервер;
- широкой глобальной индексации, русской морфологии, зрелого антиспама и полноценных индексов картинок/видео ещё нет.

Поиск по личным данным в меню запуска — отдельная функция. Он не выдаётся за интернет-поиск.

## Обязательные незавершённые работы

### Настоящий дополнительный монитор при одном физическом

Для закрытия этого требования ещё нужны:

1. Доверенно подписанный, проверенный драйверный пакет и безопасный установщик/удаление.
2. Проверка реального появления дополнительного дисплея в Windows при одном физическом мониторе.
3. Проверка полного пути IDD → Windows output → захват → Viewer на физических GPU и целевых версиях Windows.
4. Испытания выключения, сна, перезапуска, удаления устройства, RDP и восстановления без потери управления.
5. Доработка транспорта и взаимодействия там, где стандартного захвата недостаточно.
6. Полноценное управление сторонними Windows-окнами: текущий Viewer пересылает ввод только в LifeOS/Chromium.

Полноэкранное окно **не** считается виртуальным монитором. Основной физический экран не отключается автоматически. Скриптов отключения Secure Boot / проверки подписи в проекте нет.

### Полный собственный интернет-поиск

Реализован работающий пилот самостоятельной поисковой цепочки, но не полноценный сервис с широким актуальным охватом. Нужны постоянно работающая инфраструктура, больший и проверенный набор разрешённых источников, масштабирование, качество ранжирования, мониторинг свежести и эксплуатационная защита.

### Другие функции целевой спецификации

Повторяющиеся календарные события/ICS-импорт, облачная синхронизация, полное шифрование, расширения браузера/DRM-совместимость, банковские интеграции, сторонние плагины и напоминания при полностью завершённом приложении не объявляются готовыми. Список целевых возможностей в большой спецификации нельзя читать как список функций этого preview.

## Безопасность использования preview

- Не отключайте защиту Windows ради приложения или драйверных исходников.
- Проверяйте источник EXE и `SHA256SUMS.txt`; unsigned preview может вызывать предупреждение Windows.
- Не храните здесь единственную копию критичных данных. JSON-экспорт не включает содержимое внешних файлов и cookie-профили.
- Portable означает запуск без установки, **не** перенос данных рядом с EXE: профиль остаётся в пользовательском AppData.
- Веб-предпросмотр с личным RPC — локальный/dev-режим, не публичный многопользовательский хостинг.
- Перед широким публичным использованием backend и браузера нужен отдельный аудит безопасности и совместимости.
